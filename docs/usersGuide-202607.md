# GNSS Scope 利用者の手引（202607）

GNSS レシーバ（Pico W + MAX-M10S）の測位品質を、スマホで観測・記録・解析するためのアプリです。
このガイドは操作手順と画面の読み方をまとめています。機能の詳細な定義は `funcspec-202607.md`、
機器の準備は `hardware-202607.md` を参照してください。

## 1. 用意するもの

- **Android スマートフォン**（Chrome または Edge）
  ※ iPhone / iPad は Bluetooth 接続の仕組み（Web Bluetooth）に対応していないため使えません。
- **GNSS レシーバ**（Raspberry Pi Pico W + u-blox MAX-M10S、電源）
  ※ 実機が無くても、あとで説明する「モックNMEA配信」で操作を試せます。
- アプリの URL（`https://` で配信されているもの）

## 2. はじめる前に

1. スマホの **Bluetooth を ON** にします（位置情報の許可を求められた場合は許可します）。
2. Chrome でアプリの URL を開きます。
3. メニューから「**ホーム画面に追加**」を選ぶと、アプリとして起動でき、
   電波の無い場所でも起動できるようになります。
4. GNSS レシーバに電源を入れ、**空が見える場所**に置きます。
   本体の LED が点灯すれば配信の準備ができています。

> 屋外では、測位が安定するまで（初回は特に）数十秒〜数分かかることがあります。

## 3. 全体の流れ

```
 接続  →  記録  →  停止  →  保存  →  解析 / 地図で確認  →  必要ならファイル出力
（BLE）  (record)  (stop)   (save)      （load したデータ）        （CSV/GPX/JSON）
```

画面下のタブで「接続 / 記録 / 解析 / 地図 / 設定」を切り替えます。
画面上部には常に**接続状態・測位状態・最終受信からの経過秒**が表示されます。

## 4. 接続する

1. 「**接続**」タブを開き、`接続` を押します。
2. 表示されたデバイス一覧から **picow** を選び、「ペア設定」または「接続」を押します。
3. 上部の表示が「**受信中**」、測位状態が `3D` になれば正常です。

切断したいときは `切断` を押します（以後、自動での再接続は行いません）。
通信が突然切れた場合は、自動で再接続を試みます（待ち時間を延ばしながら繰り返します）。

### つながらないとき

| 症状 | 対処 |
|---|---|
| 「BLE非対応」と出る | Android の Chrome / Edge を使ってください。iPhone / iPad は非対応です |
| 「HTTPS接続が必要です」と出る | `https://` の URL、または `localhost` で開いてください |
| デバイス一覧に picow が出ない | レシーバの電源、LED の点灯、スマホの Bluetooth を確認してください |
| 接続はできるが「接続中」のまま | データが 3 秒以上届いていません。レシーバの LED とアンテナ接続を確認してください |
| 測位状態が `No fix` のまま | 空の見える場所へ移動し、数分待ってください（屋内では測位できません） |

## 5. 受信の健全性を確認する（任意）

接続タブの「受信品質」は、**レシーバからスマホまでの間で NMEA を取りこぼしていないか**を示します。
正常なら、CS NG・破棄・欠落の各項目はほぼ 0 のまま増えません。

- `受信行数 / CS NG` … 受け取った行数と、壊れていて捨てた行数
- `エポック / 欠落` … 1 秒ごとのデータ数と、抜けた秒数
- `BLE欠落（推定）` … レシーバが送った行数との差
- `Pico...` … レシーバ側のカウンタ（5 秒ごとに届きます）

数値は「統計リセット」で 0 に戻せます。測定のたびにリセットすると、その回の品質が分かります。

## 6. 記録する

測りたい地点に**レシーバを置いて動かさない**状態にしてから操作します。

1. 「**記録**」タブを開きます。「現在の測位値」に緯度経度が出ていることを確認します。
2. `⏺ 記録` を押します。上部に `● REC` が点滅し、進捗バーと散布図が表示されます。
   （「現在の測位値」は自動で畳まれます。見たいときはタップすると開きます。）
3. そのまま静止して待ちます。散布図に点が集まっていきます。
4. 自動停止（初期設定では「中心と DRMS が 10 秒横ばい」で停止）を待つか、
   `⏹ 停止` を押して止めます。
5. 停止すると**ビープ音**が鳴り、結果の見出しに停止した理由が出ます。
   この時点でデータは**「下書き」として保存済み**です。ただしまだ「地点」ではありません。
6. 地点名（初期値は `2026-07-30-01` のような日付＋連番）とメモを入れ、`💾 保存` を押します。
   これで地点になり、番号が付きます。使わない記録は `🗑 破棄` で捨てられます。

> **データが失われない仕組み**
> 記録中も **5 秒ごとに自動保存**しています。保存を押す前にアプリが終了しても、
> 直前までのデータは「下書き」として記録一覧の先頭に残るので、後から `保存` で
> 地点にできます。**下書きが勝手に消えることはありません。**

> **記録には記録専用のスマートフォンを使ってください。** 地図を見たい・写真を撮りたい
> ときは別の端末を用意します。**データが 10 秒届かないと、記録は打ち切られます**
> （画面を消した・他のアプリに切り替えた・Bluetooth が切れた・電波が届かない、など）。
> 戻ってきても続きにはなりません。もう一度 `⏺ 記録` から測り直してください。
> 記録中は自動で画面が消えないようにしています（Wake Lock）。

### 停止したときの音と表示

画面を見ていなくても分かるよう、**自動で止まったときだけ音が鳴ります**。

| 音 | 意味 | 見出しの表示 |
|---|---|---|
| 短く 2 回（ピッ ピッ） | 収束して止まった＝**良い結果** | `収束で自動停止（45秒/45点）` |
| 長く 1 回（ピー） | 上限時間で打ち切った＝**未収束**。測り直しを検討 | `上限時間で停止（未収束: 180秒/180点）` |
| 長く 1 回（ピー） | データが 10 秒届かなくなった＝**受信が切れた** | `データ途絶で停止（未収束: 45秒/40点）` |
| 鳴らない | 自分で止めた | `手動停止（…）` |

- 括弧の中は「かかった秒数 / 集まった点数」です。1 秒に 1 点なので、
  **この 2 つが大きくずれていたら**データを取りこぼしています（電波の途切れなど）。
- 30 秒以上測ったのに 10 点も集まっていない場合は、破棄するか確認が出ます。
  点数が少なすぎると「ばらつきがほぼ 0」という誤った結果になるためです。
- 音が不要なときは設定タブの「自動停止をビープ音で知らせる」を切ってください。
  端末がマナーモード・音量 0 のときは鳴りません。

### 進捗バーの見方

| バー | 意味 |
|---|---|
| 経過 | 経過時間 / 上限時間。白い縦線が「最低収集時間」の位置で、ここを越えるまでは自動停止しません |
| 最低時間 | 最低収集時間までの残り |
| 安定待ち | 判定に使える良いデータが何秒続いたか（10 秒必要）。電波が悪くなると**0 に戻ります**（赤くなります） |
| 判定中 | 10 秒揃った後。中心のふらつきと DRMS の変動幅が「実測値 / 許容値」で出ます。緑になれば条件を満たしています |

バーの下に出る「衛星 ○/○　HDOP ○　3D」は判定に使える条件です。
なかなか止まらないときは、ここが悪くなっていないか見てください。

### 散布図の下の凡例

```
● GNSS受信機   45秒間 132点  DRMS 1.24m
◎ Android内蔵  45秒間  14点  DRMS 4.81m
```

- **● 塗りつぶし = GNSS受信機**（外付けのレシーバ）、**◎ 中抜き = Android内蔵**（スマホ自身）。
  散布図の点も同じ描き分けです。色と形の両方で見分けられます。
- 点数が違うのは性能差ではありません。レシーバは 1 秒に 1 点ですが、
  スマホは動かないでいると OS が更新を減らすためです。だから秒数も併記しています。
- 「表示範囲の外側に ○点」と出たら、その点は枠の外にあります。
  枠の縁の ▲ がどちらの方向に飛んだかを示しています。

保存せずに次の記録を始めようとすると、破棄の確認が出ます。

### 詳しい結果を見る

`▶ 収束で自動停止（…）` をタップすると、集計値・2 系統の比較・測定区間の明細が開きます。
現地では散布図と凡例だけ見れば足りるので、初期状態は閉じています。
一度開くと、次の記録でも開いたままになります。

## 7. 記録を読み込む

保存した記録を「読込データ」にすると、解析タブと地図タブがその記録の内容に切り替わります。

- **保存済みから**: 記録タブの一覧で、目的の記録の `読込` を押します（読込中の行は枠が青くなります）。
- **ファイルから**: `📂 JSON取込` を押し、以前に出力した JSON ファイルを選びます。
  別の端末で測ったデータもこの方法で読み込めます。同じファイルを 2 回読んでも上書きされません。

保存直後の記録は、自動的に読込データになります。

## 8. 解析画面の読み方

「解析」タブの上部で **ライブ**（今受信している状態）と **読込データ**（保存した記録）を切り替えます。
読込データではスライダを動かすと、その記録の任意の 1 秒を再現できます。

図は 2 列で並びます。**上段が SkyPlot（左）と DRMS の散布図（右）**、**下段が SNR（左）と DOP（右）**です。
画面が狭いときは SkyPlot の衛星番号（PRN）は重なって読めなくなるため省略されます
（衛星番号を確認したい場合は端末を横向きにするか、画面の広い端末でご覧ください）。

### SkyPlot（衛星の配置）

- **中心が真上（仰角 90°）、外周が地平線（0°）**、上が北です。
- **丸が大きい = 電波が強い**、**塗りつぶし = 測位に使用中**、中抜き = 見えているだけ。
- 色は衛星の種類（凡例のとおり GPS / GLONASS / Galileo / BeiDou / QZSS）。
- 空全体に散らばっているほど測位形状が良く、片側に偏っていると精度が落ちます。
  低い仰角の衛星（外周付近）は建物や樹木の影響を受けやすく、反射（マルチパス）の原因になります。

### SNR（電波の強さ / C/N0）

棒の高さが受信強度です。おおよその目安：

| C/N0 | 状態 |
|---|---|
| 45 dBHz 以上 | 非常に良好（開けた空） |
| 40 dBHz 前後 | 良好 |
| 30 dBHz 台 | 弱め（樹林・建物の影響） |
| 20 dBHz 台以下 | かなり弱い。測位に使われないか、誤差要因になりやすい |

### DOP（衛星配置による精度の悪化度）

数値が小さいほど良い状態です。バーは緑（良）→ 橙 → 赤（悪）で色が変わります。

| HDOP | 目安 |
|---|---|
| 1 未満 | 理想的 |
| 1〜2 | 良好（通常はここを目指す） |
| 2〜5 | 実用範囲だが精度は落ちる |
| 5 以上 | 衛星配置が悪い。開けた場所へ移動を検討 |

「精度ソース」は水平精度の求め方です。`GST` はレシーバが出す誤差統計から、
`HDOP×UERE` は HDOP からの概算（設定の UERE を使用）です。

### DRMS（ばらつき）

散布図は**記録した各点が中心からどれだけ散ったか**（東西 × 南北、単位 m）を示します。

- 青い破線円 = DRMS（おおよそ全体の 6〜7 割が入る目安）
- 緑の破線円 = CEP50（半分の点が入る円）
- 点が中心付近に密集していれば安定した測位、広がっていれば環境が悪い状態です。

**表示の広さは自動で決まります。** GNSS受信機の DRMS のおよそ 4 倍が枠に収まるよう
拡大・縮小するため、ばらつきが小さい記録でも点が中心の一点に潰れません。
枠からはみ出した点は縁に ▲ で示し、その数を図の下に出します。

| DRMS の目安 | 状態 |
|---|---|
| 1 m 前後 | 開けた空・良好な条件 |
| 2〜3 m | 一般的な単独測位 |
| 5 m 以上 | 遮蔽・反射の影響が大きい |

**注意**: DRMS / CEP は「点のばらつき（精密さ）」で、真の位置からのずれ（正確さ）ではありません。
ばらついていないのに位置がずれている場合もあります。

## 9. 地図で確認する

「地図」タブでは、読込データの中心（緑）と各エポックの点（橙）、DRMS の円が地理院地図に重なります。
中心マーカーをタップすると地点名・座標・DRMS が表示されます。

- `読込データへ` … 読込中の記録が収まる位置・縮尺に戻します。
- `追従` … 受信中の現在地を画面中央に追従させます（地図を指で動かすと自動で解除されます）。
- 地図の種類（標準 / 淡色 / 写真）は設定タブで変更できます。

## 10. 設定を調整する

| 設定 | 変えるとどうなるか |
|---|---|
| UERE | GST が出ないレシーバでの水平精度の概算値が変わります（初期値 5 m のままで通常は問題ありません） |
| 収束で自動停止 | OFF にすると、上限時間・上限エポックに達するまで止まりません |
| 自動停止をビープ音で知らせる | OFF にすると停止時に音が鳴りません（周囲に人がいるときなど） |
| 記録中に Android内蔵GNSS も取得して比較する | OFF にすると散布図の比較（紫の中抜きの点）が出なくなります |
| 記録 最低収集時間 | 長くすると、早期に「安定」と判定されての停止を防げます |
| 記録 上限時間 | 収束しない環境での打ち切り時間。0 にすると収束するまで止まりません |
| 記録 収集エポック数 | 点数で打ち切ります。0 で無制限 |
| ライブ軌跡を表示 | OFF にすると地図の軌跡が消えます |

**設定はアプリを再読み込みすると初期値に戻ります。** その日だけ値を変えて測りたいときは、
記録を始める前に設定し、アプリを閉じ直さないようにしてください。
初期値そのものを変えたい場合は開発者にご相談ください（`js/constants.js` で全端末に反映されます）。

## 11. 電波の無い場所で使う（オフライン）

1. **出発前に**、電波のある場所で「設定」タブの `タイル事前ダウンロード` を押します。
2. 枚数の確認が出るので、地図種別を確かめて実行します（進捗が表示され、中止も可能です）。
3. 完了すると取得枚数と取得日時が表示されます。

以後は圏外でも、取得済み範囲の地図・BLE 受信・解析・記録がすべて動作します
（記録データも端末内に保存されます）。地図の種類を変えると、その種類のタイルは
別途ダウンロードが必要です。

## 12. 実機が無いときの確認方法

「設定」タブの `モックNMEA配信` を ON にすると、擬似的な NMEA が 1 秒ごとに流れ、
接続せずに記録・解析・地図の動作を確認できます（箕面大滝付近の座標を使用）。
確認が終わったら OFF に戻してください。

## 13. データを取り出す

記録タブの一覧から、記録ごとに出力できます。

| 形式 | 向いている用途 |
|---|---|
| **CSV** | Excel などでの分析（1 行 1 秒。末尾に集計値のコメント行が付きます） |
| **GPX** | 地図ソフト・GIS で位置を見る（中心を地点、全点を軌跡として出力） |
| **JSON** | バックアップ、別端末への移動（このアプリで読み戻せます） |

> 記録は**この端末のブラウザ内**にのみ保存されます。ブラウザのサイトデータを消すと失われるため、
> 大事な記録は JSON で保存しておいてください。

## 14. 困ったとき

| 症状 | 確認すること |
|---|---|
| 記録ボタンを押すと「有効な測位データがありません」 | 接続（またはモック配信）を開始し、緯度経度が表示されてから押してください |
| 記録が勝手に止まった（`データ途絶で停止`） | データが 10 秒届きませんでした（画面が消えた・他のアプリに切り替わった・Bluetooth が切れた・電波が届かない）。もう一度 `⏺ 記録` から測り直してください |
| 記録が勝手に止まった（`保存失敗で停止`） | 端末の空き容量が足りない可能性があります。不要な記録を削除してから測り直してください |
| 一覧に「下書き」が残っている | 保存を押していない記録です。行の `保存` を押すと地点になります。不要なら `削除` してください |
| 一覧に「記録中に中断」と出ている | 保存を押す前にアプリが終了した記録です。データは残っているので、`保存` を押せば地点にできます |
| 自動停止しない | 環境が安定していない可能性があります。進捗バーの「安定待ち」が何度も 0 に戻る（赤くなる）なら電波状況が不安定です。開けた場所へ移動するか、上限時間で打ち切ってください |
| 停止しても音が鳴らない | 自分で止めた場合は鳴りません。マナーモード・音量 0 でも鳴りません。設定の「自動停止をビープ音で知らせる」も確認してください |
| 散布図で内蔵の点が見当たらない | 凡例の `Android内蔵` の行に理由が出ます（`取得OFF` / `未許可` など）。位置情報の許可を確認してください |
| 解析タブの「読込データ」が選べない | まだ記録を読み込んでいません。記録タブで `読込` してください |
| SkyPlot / SNR が更新されない | 衛星情報（GSV）が届かない間は直前の表示を保持します。8 秒以上途切れると表示が消えます |
| 地図が灰色のまま | 圏外でタイル未取得の範囲です。事前ダウンロードを行ってください |
| 表示が古い / 不具合が直らない | 設定タブの `更新を確認` から最新版へ更新してください |
| 一覧の記録が消えた | ブラウザのサイトデータ削除、またはプライベートモードで開いた可能性があります |
| 「他のタブでこのアプリが開いています」と出る | 別のタブで古い版が開いたままです。すべて閉じてから開き直してください |
